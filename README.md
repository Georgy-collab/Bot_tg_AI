# Bot_tg_AI

Telegram-бот с диалогом через [ProxyAPI](https://proxyapi.ru/). История переписки хранится в памяти процесса: каждый чат помнит свои реплики, пока бот запущен. В запрос к модели попадают только последние 20 сообщений, более старые удаляются. После перезапуска контекст пропадает.

## Стек

- Python 3.12
- [aiogram](https://docs.aiogram.dev/) — бот Telegram
- `requests` — запросы к `https://api.proxyapi.ru/v1/chat/completions`
- `python-dotenv` — ключи из `.env`

## Файлы

| Файл | Назначение |
| --- | --- |
| `bot.py` | Команды, диалог и логи |
| `config.py` | Ключи и параметры модели |
| `context_manager.py` | История диалога в памяти |
| `api_client.py` | Запрос к ProxyAPI |

## Модель

Используется одна модель: `openai/gpt-5-mini`.

- Температура в запрос не передаётся. У модели остаётся её значение по умолчанию.
- Длина ответа ограничена `max_completion_tokens`: **5000**. У этой модели поле `max_tokens` не принимается.

## Ключи

Оба ключа лежат в `.env`. Файл не коммитится.

```text
BOT_TOKEN=токен_от_BotFather
PROXY_API_KEY=ваш_ключ
```

**BOT_TOKEN.** В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и скопируйте выданный токен.

**PROXY_API_KEY.** Это ключ кабинета ProxyAPI, а не ключ OpenAI.

1. Зарегистрируйтесь в [консоли ProxyAPI](https://console.proxyapi.ru/register) и подтвердите почту.
2. Откройте раздел [Ключи API](https://console.proxyapi.ru/keys) и нажмите «Создать новый ключ API».
3. Скопируйте строку, которая начинается с `sk-`. Целиком она показывается только сразу после создания. Если ключ потерян, создайте новый.

Пока на балансе нет денег, запрос не выполнится. Пополнение — в разделе «Биллинг» того же кабинета. Подробности — в [документации по ключам](https://proxyapi.ru/docs/api-keys).

## Установка

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Если `.env` уже есть, допишите в него `BOT_TOKEN`.

## Запуск

```powershell
python bot.py
```

Остановка — Ctrl+C.

Прямое соединение с `api.telegram.org` с этого компьютера не открывается. Бот берёт системный прокси Windows. Свой адрес можно задать в `.env` строкой `TELEGRAM_PROXY=http://127.0.0.1:10809`. Если переменная пустая, используется системный прокси.

## Команды

- Обычное сообщение продолжает диалог. В запрос уходят последние 20 сообщений этого чата.
- `/context` или текст `справка` показывает, сколько сообщений в истории, сколько из них ваших и ответов бота, объём в символах, модель и лимит ответа.
- `/reset` или текст `очистить контекст` стирает историю чата.
- `/start` кратко объясняет, как пользоваться ботом.

## Логи

В консоли пишутся параметры каждого запроса (`model`, температура по умолчанию, `max_completion_tokens`, число сообщений) и ошибки: сеть, ответ API, пустой ответ модели. Ключи в лог не попадают.
